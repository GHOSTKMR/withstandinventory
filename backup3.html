Important notes

  • Google Sheets is the shared source of truth; browser local storage is used only to remember this URL and temporary interface preferences.
  • Saving updates a matching date and item code row. If your backend only updates existing rows, the date/item row must already exist in the target tab.
  • Opening stock may be protected by sheet formulas. This page does not change sheet formulas or create missing rows.
  • Notes are kept in this browser only; the current Apps Script save endpoint does not store them.
  • Do not use this app for live stock until a test entry has been checked in the sheet.
